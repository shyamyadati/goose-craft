# goose-craft
One small step for a Kerbal. On giant leap for Kerbal kind.

## What is goose-craft

Goose craft is a tool for the Goose agent that helps create air and spacecraft within Kerbal Space Program. 

## Architecture

Goose Craft provides a set of tools for the goos agent to interact with Kerbal Space Program to create, test and evolve craft. It allows Goose and open source models to create meta-craft files which then are tranlsted into KSP Craft files. It also allows Goose to create fly-scripts that can be used  to fly missions, and collect data to refine help refine and optimize the aircraft design.
